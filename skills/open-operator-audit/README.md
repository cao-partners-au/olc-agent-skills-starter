# open-operator-audit

Combined SEO and GEO (generative engine optimisation) audit: how visible is the site to search AND to AI assistants.

**When in the sequence:** any time; useful before paid spend  
**Rough time:** 1 hour

## Before you start, you need

- A public URL
- Nothing else

## It will ask you for

- The site to audit, and any competitors to compare against

## What it will not do

- Fix anything. It produces a prioritised list with paste-ready code.

## Worth knowing

Worth running before paid channels: paid traffic landing on a page that converts badly is an expensive way to discover a content problem.

---

Invoke it by name in your agent (`/open-operator-audit`), or just describe the task - the
skill's description lists the phrases that should trigger it.
